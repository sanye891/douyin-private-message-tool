## 🚀 三步跑起来

```bash
pip install -r requirements.txt && npm install
```

`.env` 里填上你的登录 Cookie：

```ini
DY_COOKIES='登录 www.douyin.com 后 F12 复制的完整 cookie'
```

运行：

```bash
python main.py
```

输入 `send 用户UID 你好` 即刻送达，`reply` 一秒回复最近私信。
